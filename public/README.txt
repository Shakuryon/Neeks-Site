NEEKSTARS VOICE PORTFOLIO — HANDOFF NOTES

Files:
- index.html: page structure and content
- styles.css: visual system, colors, animation, desktop styling
- media.css: tablet/mobile overrides
- index.js: mobile navigation, audio sample controls, scroll and reveal effects

Before launch:
1. Add an assets folder with:
   - assets/neekstars-avatar.png (approved profile image/artwork)
   - assets/audio/character-demo.mp3
   - assets/audio/animation-demo.mp3
   - assets/audio/game-demo.mp3
2. Replace the generic social profile links with Neekstars' confirmed URLs.
3. Confirm the biography, pronouns, recording setup, availability, and all claims with Neekstars.
4. The contact form currently opens the visitor's email app via mailto. For a proper hosted form, connect Web3Forms or another service using Neekstars' own account/key.
5. No third-party artwork has been copied into this build; the design uses CSS-created stars, shapes, and abstract graphic motifs inspired by the requested references.

The HTML references the original class/section naming pattern where practical, including heroSection, charsSection, aboutKelvin, equipmentSection, contact, footerSection, and existing template class families.
